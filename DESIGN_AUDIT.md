# Niksmarvel Online Enrollment Form — Humanized Audit

## Scope
This revision is intentionally **form-only**. It does not turn the page into an academy marketing website.

## Client-field constraint
**No new applicant, guardian, declaration, upload, or contact fields were added.** Existing field names, values, required states, file types, and submission payload structure were preserved.

## UX improvements
- Form-first layout with a restrained branded header.
- Removed website-style navigation and marketing sections.
- Added a non-interactive section progress cue; it does not create a new field.
- Clear required-field instruction and security note.
- Stronger visual grouping between the three existing form sections.
- Larger, more usable mobile controls.
- Full-width upload hit area while preserving the same two existing upload fields.
- Clearer radio-option grouping.
- More visible focus states and keyboard-friendly controls.
- Native browser validation retained; invalid focus is brought to the first problem.
- Clear success/error feedback retained.
- Reduced-motion support retained.

## Research basis
The design follows W3C/WAI form guidance: keep forms focused, use visible labels, group related controls, provide instructions before they are needed, make errors identifiable, and design for mobile/accessible interaction.

## Deliberately not added
- No new fields
- No account creation
- No password fields
- No marketing pages
- No testimonials
- No extra application questions
- No new backend data requirements
